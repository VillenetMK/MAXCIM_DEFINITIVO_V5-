# Fuente Massallera

Coloca en esta carpeta el archivo `massallera.woff2`. Opcionalmente, agrega también `massallera.woff` como formato de respaldo.

La persona docente o el equipo de desarrollo es responsable de obtener la fuente y verificar que su licencia permita usarla en MAXCIM. Los archivos de la fuente no se incluyen en el repositorio.
